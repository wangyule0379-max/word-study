# 词芽 WordSprout v1.0

面向七年级学生的家庭单词练习器。先复习、再学新词、最后独立拼写；不登录、不含广告、不接大模型 API。

## 最快开始

下载单独的 HTML 文件，或打开本包的 `site/index.html`。电脑上用 Chrome、Edge 或 Safari 打开，不要只停留在聊天附件/文件预览里。

进入 **设置与备份 → 测试发音**，确认能听到 “Hello. My hobby is reading.”。随后回到 **今日练习 → 开始今日练习**。默认新词上限为 6 个、每轮复习上限为 12 个，可在设置中调整。

本地文件模式适合先试用。正式长期使用建议把 `site` 文件夹部署到固定网址，然后始终在同一个浏览器打开。

## 这个版本能做什么

发音与慢读、中文释义、练习例句、词形小提醒；看词回忆、中文拼写、听写、句中填空；错词分类与有限重试；按日复习；保存正在进行的训练和未提交的输入草稿；词库搜索、CSV/JSON 导入；完整备份与恢复；手机、平板、桌面适配。

不能做的事情：不自动跨设备同步；不做录音和口语评分；不含真人录制音频；不保证断网发音；不自动判断导入词表是否属于某版教材；未部署公开网址；不是完整七上或七下教材词库。

## 词库范围

内置 20 个**示例练习词**，来自此前讨论的 Starter / Unit 1 练习选择，不是经出版社授权的完整词表，也没有声称与孩子实际课本逐页一致。例句和填空练习由本项目编写。

Unit 1：mistake、important、remember、problem、advice、task、polite、protect、together、hope。
Starter：ready、introduce、classmate、hobby、activity、join、enjoy、nervous、holiday、uniform。

以孩子的课后词表为准核对英文、词性、释义与单元。添加新单元后，到学习设置选择它。换单元不会重新获得当天新词额度；到期复习会跨单元安排，避免旧词被遗忘。

## 每日怎么使用

孩子先点「开始今日练习」。到期旧词先回忆；新词先看中文、听发音、读例句；之后进入拼写/听写以及最多 5 道句中练习。没有旧词的第一天会直接学新词。

想不出时可点「暂时不会」。点「看答案」会记为使用了提示，不算独立答对。错题在隔几步后再出现，每题最多重试两次，不会无限循环。今天改对的错词仍会留下，翌日独立答对后解除标记。

单词的新学不是掌握证明。复习日期使用设备本地日期，间隔按 1、3、7、14、30 天递进；同一天反复答对不会跳阶段。错题回到次日复习。已浏览却未做拼写的新词，在结束未完成训练后仍可继续安排检验，不会被误认成完成全部任务。

结束后查看独立拼写正确率，不只看新学了多少词。认义的自我评价不计入拼写成绩。家长每周抽查旧词，比单看浏览数更能了解孩子实际表现。

「拼写专项」「听写专项」属于额外自主练习，也会产生学习记录，练到未学过的词也会计入当天已新学词数。日常先用每日计划，不必不断刷专项。

## 发音说明

使用浏览器 Web Speech API 和系统提供的英语合成声音。自动选择顺序是：本地且符合优先口音的声音 → 其他本地英语声音 → 符合口音的在线声音 → 其他英语声音。手工选定的声音优先于自动选择。

首次请手动点击发音按钮，没有自动播放。若声音列表尚未加载，浏览器会尝试对应语言的默认声音。没有启动、播放错误或超时，页面会给出提示；听写题可以直接改为看中文拼写，不会把语音故障算作答错。

本工具不申请麦克风权限，也不主动上传学习记录。但系统的非本地合成声音可能将播放文字发送到其语音服务。对联网有顾虑时，只选标记为「本地」的声音并在目标设备上试听。

实际音色、可用性、声音是否需要联网，依赖设备与浏览器。本环境验证了语音控制逻辑及失败回退，不能代替在孩子设备上的试听。

## 保存与备份

一个浏览器、一个网站地址对应一套本地记录，适合一名孩子使用。程序在每步操作和输入时尝试保存；检测到失败会持续显示「未能保存」，不能把临时页面状态当作已经备份。

`file:` 本地文件的存储行为并非浏览器统一保证；移动文件、换浏览器、隐私/无痕窗口、清理网站数据，都可能让原记录不可见或被删除。固定 HTTPS 网站地址更适合长期使用，但仍需导出备份。

进入 **设置与备份 → 导出当前备份**，得到 JSON 文件。它包含词库、设置、每日汇总、错词、近期逐题明细和进行中的训练。清理浏览器、换机、换域名前先导出，在新的地址或设备里恢复。

恢复前会预览数量并要求确认，恢复会替换当前浏览器的数据。文件不合法时不替换；保存失败时也不替换。损坏的原记录不会自动覆盖，可先导出原始内容。多个标签页同时使用时，旧页面会暂停写入，要求加载最新记录，避免互相覆盖。

单独导出备份不等于云同步。不要将含孩子个人信息的词库或学习备份上传为公开网站文件。部署只需 `site/index.html`。

## 导入自己的词库

点 **下载 CSV 模板**，或编辑包内 `词库导入模板.csv`。保存为 UTF-8 编码 CSV，再点「选择词库文件」。也支持包含词条数组的 JSON。

必填 `word`（英文）、`meaning`（中文）。可选字段：

| 字段 | 用途 |
| --- | --- |
| unit | 单元名，未提供则为自定义单元 |
| pos | 词性，例如 n.、v.、adj. |
| example | 英语例句 |
| exampleZh | 中文例句 |
| tip | 拼写/语法提醒 |
| cloze | 句中填空，必须含四个下划线 `____` |
| answer | cloze 的准确答案，必须与 cloze 同时提供 |
| id | 通常不用填写，由程序生成 |

例如：

```json
[
  {
    "unit": "我的课本 Unit 2",
    "word": "tree",
    "pos": "n.",
    "meaning": "树",
    "example": "A tree grows in our garden.",
    "exampleZh": "一棵树长在我们的花园里。",
    "tip": "复数 trees。",
    "cloze": "There are two ____ in the garden. (tree)",
    "answer": "trees"
  }
]
```

同单元、同英文词不允许重复导入；不同单元可有同一个英文词。已经存在的词条不被静默覆盖。总词库最多 2,000 词，文件最大 3 MB；个别字段也有长度限制。未完成的训练需先完成或明确结束，再导入。

程序是对目标课本词的严格拼写检查，不是自由翻译评分。如果同一单元含多个中文同义词，请在 meaning 或词性字段中补充足以区分的语境，避免模棱两可的题目。复杂同义词容错和自由句子评价不属于本版功能。

## 让手机通过固定网址使用

本包的 `site` 文件夹仅含已构建的 `index.html`，不需要 npm 构建，也不需要服务器数据库。

可使用 Cloudflare Pages 的 Direct Upload。官方流程是进入 Workers & Pages，选择 Create application → Get started → Drag and drop your files，填写项目名，上传 `site` 文件夹，再部署。界面文字可能因账号语言不同而不同。拖拽方式支持文件夹或 ZIP；请保证 `index.html` 在上传内容根目录。

仅上传 `site`，不要把源码、测试截图或学习备份一起公开。部署后复制实际获得的网址，在手机浏览器打开；不要使用文档中的示例域名作为真实地址。这里没有代为登录、创建或发布 Cloudflare 项目。

新网址与原本地文件是不同存储位置：先在电脑导出备份，再在手机的新网址恢复。以后手机和电脑仍不会自动同步，请尽量固定一台主要学习设备。

若你的网络无法打开某个托管网址，可使用自己能稳定访问的静态网站空间。本项目不保证 Cloudflare 默认域名在任何网络环境下都可达。

## 源码与测试

`source/src/core.js`：学习状态、日期、题目、评分、词库/备份验证。
`source/src/data.js`：示例词库。
`source/src/app.js`：页面、发音、存储、导入与恢复。
`source/src/style.css`：响应式样式。
`source/src/shell.html`：HTML 外壳。
`source/build.py`：将以上文件内联为单文件 `index.html`。

修改源码后，在 `source` 文件夹执行：

```bash
python3 build.py
npm test
```

生成的 `source/index.html` 才是修改后的网页；将它替换到 `site/index.html` 再部署。运行网页本身不需要安装 Python 或 Node。

UI 测试需要 Python Playwright 和 Chromium。测试环境与范围见 `QA.md`。
